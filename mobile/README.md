# کادوپیچ — اپ Android و iOS

نسخه‌ی اول اپ کادوپیچ با Expo و React Native ساخته شده است.

## امکانات

- پیشنهاد هدیه بر اساس ۸ سؤال
- نمایش ۱۲ پیشنهاد از میان ایده‌های متنوع
- ذخیره‌ی علاقه‌مندی‌ها روی دستگاه
- اشتراک‌گذاری پیشنهادها
- ثبت مناسبت و زمان‌بندی یادآور محلی
- رابط فارسی و راست‌چین

## اجرا

پیش‌نیاز: Node.js 22.13 یا جدیدتر.

```bash
npm install
npx expo start
```

سپس QR را با Expo Go اسکن کنید یا کلید `a` را برای Android و `i` را برای iOS بزنید.

یادآورهای محلی روی دستگاه واقعی بهتر تست می‌شوند. برای ساخت نسخه‌ی انتشار، پروژه را به EAS متصل کنید و `eas build --platform all` را اجرا کنید.

## ساختار

- `App.js`: رابط، پیشنهادگر، علاقه‌مندی‌ها، اشتراک‌گذاری و یادآورها
- `assets/logo.png`: لوگوی کادوپیچ
- `app.json`: تنظیمات Android، iOS و اعلان‌ها
