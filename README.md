# کادوپیچ

پیشنهادگر فارسی هدیه برای وب، Android و iOS.

## ساختار پروژه

- `web/`: نسخه‌ی وب استاتیک و راست‌چین
- `mobile/`: اپ React Native و Expo برای Android و iOS

## امکانات

- پیشنهاد ۱۲ هدیه از میان ایده‌های متنوع بر اساس ۸ سؤال
- لینک فروشگاه‌ها و سازنده‌های ایرانی
- ذخیره‌ی هدیه‌های محبوب
- اشتراک‌گذاری پیشنهادها
- یادآوری مناسبت‌ها
- رابط فارسی و هویت بصری کادوپیچ

## اجرای وب

```bash
cd web
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

## اجرای اپ

```bash
cd mobile
npm install
npx expo start
```

جزئیات بیشتر در `mobile/README.md` آمده است.
